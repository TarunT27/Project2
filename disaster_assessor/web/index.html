      Data & privacy

      Uploads are processed in memory on the machine running this server. The server keeps the last 10 runs in memory only and writes nothing to disk except short-lived temp files for video decoding.

      OpenStreetMap tiles are requested for the visible region. Image files are never sent to them.

      The server binds to localhost and has no authentication. Add access control before exposing it on a network: imagery and EXIF can reveal sensitive locations.

      Detections in demo mode are synthetic. Real-model outputs are unverified and need review by qualified personnel.
